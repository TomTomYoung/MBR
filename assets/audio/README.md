# 音素材

bgmは4曲、ambienceは2種、sfxは18種のOGGです。mastersには同じ用途名のWAV原本を保存しています。preview.htmlを開くと全24点を試聴できます。制作時番号と本番名の対応、全長ループの可否、再生時間は../asset-manifest.jsonを参照してください。

音は今回のために作曲・合成したもので、音声・市販楽曲・外部サンプルは使用していません。生成コードと元の説明は../source/20260920に保管しています。

アプリはsrc/audio-assets.jsでOGGのみをバンドルし、src/audio.jsでユーザーの音ON操作後に再生します。音OFFとタブ非表示で音楽・環境音・効果音を停止します。BGMは同じ画面で再描画しても先頭から再開せず、結末の曲は一度再生して終わります。

broadcast-chimeとdistant-gunshotは予備素材です。今後は本文のどの客観描写へ付けるかを決めてから接続します。
